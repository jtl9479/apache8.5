## 5. JSP 배포 방법

### 5-1. JSP 파일 배포 (일반)

JSP 파일은 컴파일 없이 배포 가능합니다.

1. 수정한 JSP 파일을 `webapps\ROOT\inno\` 경로에 복사
2. 톰캣이 실행 중이면 자동으로 반영됨 (autoDeploy=true 설정)
3. 반영이 안 될 경우 톰캣 재시작

```
배포 대상 경로: d:\PDA\apache-tomcat-8.5.29\apache-tomcat-8.5.29\webapps\ROOT\inno\
```

### 5-2. 배포 시 주의사항

- JSP 파일은 **UTF-8** 인코딩으로 저장할 것
- `db_connection.jsp`는 운영/개발 DB 접속 정보가 다를 수 있으므로 주의
- 배포 전 반드시 백업 수행

### 5-3. 배포 확인

1. 톰캣 로그 확인: `logs\catalina.out` 또는 콘솔 출력
2. 각 JSP 호출 시 `System.out.println`으로 출력되는 로그 확인
   - 예: `##search_shipment query :` 로 시작하는 로그로 쿼리 확인 가능

```xml
           connectionTimeout="20000"
           redirectPort="58444"
           URIEncoding="UTF-8" />
```

## 10. 테스트 방법

### 10-1. 브라우저에서 직접 테스트

톰캣 시작 후 브라우저 주소창에 URL을 입력하여 JSP를 직접 호출할 수 있습니다.

**기본 동작 확인:**
```
http://localhost:4040/inno/test.html
```
→ `test` 텍스트가 표시되면 톰캣 정상 동작

**DB 연결 확인:**
```
http://localhost:4040/inno/test.jsp
```
→ 톰캣 콘솔에 `INNO DB 연결 성공` 로그가 출력되면 DB 연결 정상

### 10-2. SELECT 조회 JSP 테스트

조회 JSP는 `data` 파라미터로 WHERE 조건을 전달합니다.

**출하 조회 (search_shipment.jsp):**
```
http://localhost:4040/inno/search_shipment.jsp
```
→ WHERE 조건이 고정되어 있으므로 파라미터 없이 호출 가능
→ 결과가 `::` 구분자, `;;` 행 구분자로 출력됨

**계근 조회 (search_goods_wet.jsp):**
```
http://localhost:4040/inno/search_goods_wet.jsp?data= WHERE 출고상세SEQ = 123
```
→ `data` 파라미터에 WHERE 조건을 전달

**바코드 정보 조회 (search_barcode_info.jsp):**
```
http://localhost:4040/inno/search_barcode_info.jsp?data= WHERE 품목코드 = 'XXXX'
```

### 10-3. INSERT JSP 테스트

INSERT JSP는 `data` 파라미터에 `::` 구분자로 값을 전달합니다.

**계근 입력 (insert_goods_wet.jsp):**
```
http://localhost:4040/inno/insert_goods_wet.jsp?data=출고상세SEQ::중량::중량단위::ppCode::바코드::패커코드::제조일자::박스시리얼::순번::사원코드::회사코드
```
→ 성공 시 `s`, 실패 시 `f` + 에러메시지 출력

### 10-4. 톰캣 콘솔 로그 확인

테스트 시 톰캣 콘솔 창에서 실시간 로그를 확인합니다.

| 로그 패턴 | 설명 |
|-----------|------|
| `##search_shipment all parameter :` | 전달받은 파라미터 확인 |
| `##search_shipment query :` | 실행된 SQL 쿼리 전문 확인 |
| `##insert_goods_wet query start` | INSERT 쿼리 실행 시작 |
| `##insert_goods_wet parameter :` | INSERT 파라미터 값 확인 |
| `INNO DB 연결 성공` | DB 연결 정상 |
| `INNO DB 연결 실패` | DB 연결 실패 |

### 10-5. 응답 데이터 형식

조회 JSP의 응답은 아래 형식으로 반환됩니다. PDA 앱에서 이 형식을 파싱합니다.

```
컬럼1값::컬럼2값::컬럼3값::...::컬럼N값;;
컬럼1값::컬럼2값::컬럼3값::...::컬럼N값;;
```
- `::` — 컬럼 구분자
- `;;` — 행(row) 구분자

### 10-6. 자주 발생하는 문제

| 증상 | 원인 | 해결 |
|------|------|------|
| 톰캣이 시작되지 않음 | JAVA_HOME 미설정 | 환경변수 `JAVA_HOME=D:\SUNIN_ERP\jdk-1.8` 설정 |
| 포트 충돌 에러 | 4040 포트 사용 중 | 기존 프로세스 종료 또는 `server.xml`에서 포트 변경 |
| DB 연결 실패 | DB 서버 접근 불가 | 방화벽/VPN 확인, `db_connection.jsp`의 접속정보 확인 |
| 한글 깨짐 | 인코딩 문제 | JSP 파일을 UTF-8로 저장, `URIEncoding="UTF-8"` 확인 |
| JSP 수정 반영 안됨 | 캐시 문제 | 톰캣 재시작 또는 `work\` 폴더 삭제 후 재시작 |
